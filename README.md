# MySQL-Assignment-E-Commerce-Customer-Churn-Analysis
SQL-based e-commerce customer churn analysis covering data cleaning, transformation, exploratory analysis, and customer returns using MySQL.

E-Commerce Customer Churn Analysis Using SQL

This project focuses on cleaning, transforming, and analyzing an e-commerce customer churn dataset using MySQL and MySQL Workbench.

The assignment covers data cleaning, handling missing values, outlier removal, standardizing inconsistent values, renaming columns, creating new columns, and performing exploratory data analysis using SQL queries.

It also includes aggregate functions, subqueries, filtering, grouping, and joins to analyze customer behavior, churn patterns, payment preferences, coupon usage, satisfaction scores, cashback amounts, and customer returns.

Tools Used: MySQL, MySQL Workbench
Key Skills: SQL, Data Cleaning, Data Transformation, Exploratory Data Analysis, Aggregate Functions, Subqueries, and Joins.

Objective: To derive meaningful insights from customer data and explore factors associated with customer churn and customer retention.
